# 🏎️ Super Trunfo F1

Exercício desenvolvido para a disciplina de **Soluções Mobile** — UNISATC.

Aplicativo React Native no estilo Super Trunfo com cartas de pilotos de Fórmula 1.

---

## 📱 Funcionalidades

- Exibição de cartas de pilotos da F1
- Navegação entre pilotos com botões Anterior / Próximo
- Indicador de posição com dots animados
- Informações exibidas por carta:
  - Nome do piloto
  - Descrição
  - Equipe
  - País
  - Número de estrelas ⭐
  - Imagem do piloto

---

## 🛠️ Tecnologias

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- JavaScript (ES6+)
- StyleSheet (CSS via React Native)

---

## 🚀 Como rodar

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- [Expo CLI](https://docs.expo.dev/get-started/installation/) instalado
- App **Expo Go** no celular (Android ou iOS) — ou emulador configurado

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/super-trunfo-f1.git
cd super-trunfo-f1

# 2. Instale as dependências
npm install

# 3. Inicie o projeto
npx expo start
```

Escaneie o QR Code com o app **Expo Go** para visualizar no celular.
